# Android Development with Kotlin

A comprehensive learning path covering Kotlin as a language and Jetpack Compose as a declarative UI framework for building modern Android applications. The first half focuses on Kotlin fundamentals — from syntax and null safety through coroutines and ecosystem patterns. The second half covers Jetpack Compose, navigation, data loading, animations, and production app architecture.

## Prerequisites

- Basic programming concepts (variables, functions, control flow)
- Familiarity with object-oriented programming principles
- Android Studio installed (latest stable version recommended)

## What You'll Learn

This path takes you from Kotlin language fundamentals through advanced concurrency patterns, then into Jetpack Compose's declarative paradigm for building modern Android applications. By the end, you'll understand how to architect production-ready apps using current best practices including MVVM, Hilt, Room, and multi-module projects.
