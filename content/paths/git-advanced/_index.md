# Git Advanced

Master the internals, workflows, and advanced techniques that separate everyday Git users from power users. This path dives deep into how Git works under the hood and how to leverage that knowledge for complex collaboration scenarios, recovery operations, and automation.

## What You'll Learn

| Section | Topic | Key Skills |
|---------|-------|------------|
| 01 | Git Internals | Object model, SHA-1 hashing, plumbing commands |
| 02 | Rebase Workflows | Interactive rebase, history rewriting, autosquash |
| 03 | Reflog & Recovery | Recovering lost commits, undoing mistakes |
| 04 | Advanced Branching | Worktrees, bisect, cherry-pick, sparse checkout |
| 05 | Submodules & Subtrees | Multi-repo strategies, monorepo tooling |
| 06 | Hooks & Automation | Pre-commit, CI integration, commit validation |
| 07 | Collaboration at Scale | Workflow comparison, merge queues, signed commits |
| 08 | Troubleshooting | Conflict resolution, large files, repo cleanup |

## Prerequisites

Before starting this path, you should be comfortable with:

- Basic Git operations (clone, add, commit, push, pull, branch, merge)
- Working with remotes and pull/merge requests
- Basic branching and merging strategies

These fundamentals are covered in the **[Tools path — Git section]({{< relref "/paths/tools/01-git" >}})**.

## Who This Path Is For

- Developers who use Git daily but want to understand what happens beneath the surface
- Team leads designing branching strategies and CI/CD workflows
- Anyone who has lost work in Git and wants to never feel helpless again
