# Databases & SQL

A comprehensive path through database theory and practice — from relational fundamentals and SQL mastery to NoSQL systems and production optimization.

## Sections

1. **Relational Database Fundamentals** — tables, rows, columns, keys, relationships, RDBMS landscape
2. **SQL Basics** — SELECT, INSERT, UPDATE, DELETE, filtering, sorting, aliasing
3. **Joins and Subqueries** — INNER, LEFT, RIGHT, FULL, CROSS, self-joins, correlated subqueries, CTEs
4. **Aggregations and Grouping** — GROUP BY, HAVING, window functions, analytical queries
5. **Data Definition and Constraints** — CREATE, ALTER, DROP, constraints, data types, defaults
6. **Normalization and Schema Design** — 1NF through 3NF/BCNF, denormalization tradeoffs, ERD modeling
7. **Indexing and Query Optimization** — B-trees, covering indexes, EXPLAIN plans, slow query diagnosis
8. **Transactions and Concurrency** — ACID, isolation levels, locking, deadlocks, MVCC
9. **NoSQL Concepts** — document stores, key-value, column-family, graph databases, when to use what
10. **Database Administration** — backups, replication, partitioning, connection pooling, monitoring

## Prerequisites

- Basic programming knowledge (any language)
- Command-line familiarity

## What You'll Be Able To Do

- Design normalized database schemas from business requirements
- Write complex SQL queries including window functions and CTEs
- Optimize slow queries using indexes and execution plans
- Choose between relational and NoSQL for different use cases
- Understand transaction isolation and concurrency control
