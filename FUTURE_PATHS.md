# Future Learning Paths — Ideas

Suggestions for new learning paths to add to the site.

---

## Systems & Infrastructure

- **Docker & Containers** — ~~done (moved to Tools)~~
- **Kubernetes** — pods, services, deployments, Helm, operators, networking, RBAC
- **Linux Administration** — filesystem hierarchy, users/groups, systemd, package management, hardening, cron
- **Databases** — relational design, SQL deep dive, indexing, NoSQL (MongoDB, Redis, DynamoDB), replication, sharding

## Programming Languages

- **Go** — goroutines, channels, interfaces, standard library, CLIs, microservices
- **Rust** — ownership, borrowing, lifetimes, traits, async, systems programming
- **C / C++** — memory management, pointers, compilation, STL, embedded systems

## Architecture & Design

- **System Design** — load balancers, caching, message queues, distributed systems, CAP theorem, consistency patterns
- **Design Patterns** — GoF patterns, architectural patterns (MVC, hexagonal, event-driven, CQRS)
- **API Design** — REST, GraphQL, gRPC, versioning, pagination, authentication, rate limiting

## Data

- **Data Engineering** — ETL/ELT, data lakes, warehouses, Spark, Airflow, streaming (Kafka)
- **SQL Deep Dive** — window functions, CTEs, recursive queries, query optimization, execution plans
- **Machine Learning (Classical)** — regression, classification, clustering, feature engineering, scikit-learn

## DevOps & Quality

- **CI/CD** — pipelines, GitLab CI/GitHub Actions, deployment strategies, feature flags, artifact management
- **Observability** — metrics, logs, traces, Datadog/Prometheus/Grafana, SLOs/SLIs/SLAs, alerting
- **Testing** — unit/integration/e2e strategies, TDD, property-based testing, load testing, contract testing

## Web & Mobile

- **Web Security** — OWASP Top 10, XSS, CSRF, CSP, authentication patterns (OAuth 2.0, OIDC, JWT)
- **Progressive Web Apps** — service workers, offline-first, push notifications, Web APIs
- **Android (Kotlin + Jetpack Compose)** — mirrors the Swift/SwiftUI path for Android development

## Other

- **Regular Expressions** — syntax, engines, lookaheads/lookbehinds, performance pitfalls, practical recipes
- **Math for Programmers** — discrete math, linear algebra, probability, statistics, Big-O analysis
